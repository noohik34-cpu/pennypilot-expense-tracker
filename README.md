PennyPilot – Smart Personal Finance & Expense Analytics Dashboard

Your Money. Your Control.

PennyPilot is a Python-based personal finance management application that helps users track income and expenses, manage budgets, and analyze their spending habits.

Features

- Track income and expenses
- View transaction history
- Manage monthly budgets
- Analyze expenses with charts
- Store transactions using SQLite

Tech Stack

- Python
- Streamlit
- SQLite
- Pandas
- Plotly

Installation

1. Clone this repository:
   "git clone YOUR_REPOSITORY_URL"

2. Install dependencies:
   "pip install -r requirements.txt"

3. Run the application:
   "python -m streamlit run app.py"

Project Goal

Built as a beginner-friendly portfolio project to practice Python, database management, and data visualization.
